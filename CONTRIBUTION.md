# Contributing to GSAP Effect Animations

Thank you for considering contributing!

## Getting Started

1. Fork the repository.
2. Clone your fork: `git clone https://github.com/PhatJack/gsap-effect-animations`
3. Install dependencies: `pnpm install`.

## How to Report a Bug

- Use the **GitHub Issue Tracker**.
- Describe the bug and provide steps to reproduce it.
- Include your OS and environment version.

## Pull Request Guidelines

- Create a new branch for every feature or bug fix.
- Keep PRs "atomic"—one PR per feature.
- Follow the existing code style.
- Link the PR to its related issue.
